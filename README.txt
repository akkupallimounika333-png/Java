# CineBook JavaScript Movie Booking Demo

## Files
- `index.html` — movie listing and launch page
- `booking.html` — booking form
- `style.css` — styling
- `script.js` — opens the booking popup
- `booking.js` — ticket total, validation, confirmation, and popup closing

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Click **Book tickets** on a movie.
4. Choose a show time and ticket count, then click **Confirm booking**.
5. After the success message, the popup closes automatically.

If the popup does not open, allow popups for the page and try again. Browser security normally prevents a page from closing a tab that was opened manually.

This is a front-end demo only. It does not store bookings, connect to a cinema, or process payments. For a real booking system, add a backend, database, authentication, seat availability, and a payment provider.
